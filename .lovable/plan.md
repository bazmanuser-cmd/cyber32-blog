## خلاصه

شما درخواست یک بازطراحی کامل و افزودن ده‌ها ماژول جدید (دوره، اشتراک، فضای ابری ۱GB، 2FA، RBAC، تیکت، پرداخت، پنل ادمین کامل، ۱۵+ صفحه جدید، امنیت OWASP کامل و...) به وبلاگ فعلی Cyber 32 داده‌اید، **بدون حذف هیچ قابلیت موجود**.

## واقعیت فنی که باید بدانید

این حجم کار معادل **۲ تا ۳ ماه توسعه یک تیم** است، نه یک پیام. اگر همه را در یک نوبت بزنم:
- کیفیت پایین می‌آید، باگ‌های امنیتی جدی وارد می‌شود (برعکس هدف شما).
- محدودیت‌های سکو (Lovable Cloud = Supabase + Cloudflare Workers) بعضی موارد را نمی‌پذیرد: مثلاً **Laravel/NestJS/Docker/Nginx/MySQL/Redis نصب نمی‌شود** — استک فعلی TanStack Start + Supabase (Postgres) است و باید در همین باقی بماند.
- بعضی موارد نیاز به سرویس/هزینه خارجی دارند: **پیامک (SMS) نیاز به Twilio/Kavenegar + سکرت پولی**، **پرداخت** نیاز به درگاه، **CDN/HSTS/TLS** توسط زیرساخت Lovable خودکار انجام می‌شود.

## پیشنهاد: اجرا در فازها

من پیشنهاد می‌کنم به این ترتیب پیش برویم — هر فاز در یک پیام کامل و تست‌شده تحویل داده می‌شود:

### فاز ۱ — پایه‌های پلتفرم (شروع همین حالا)
- طراحی جدید Dark + نئون سبز/آبی + Glassmorphism + فونت فارسی حرفه‌ای (Vazirmatn)
- ساختار روت‌های اصلی: `/`, `/courses`, `/articles`, `/about`, `/contact`, `/faq`, `/privacy`, `/terms`, `/login`, `/register`, `/forgot-password`, `/dashboard`, `/admin`, `/404`
- صفحه اصلی کامل: Hero + اسلایدر + آمار + تیم + FAQ + فوتر
- سیستم RBAC (نقش‌ها: owner, admin, instructor, author, vip, user) با جدول `user_roles` امن
- SEO پایه + sitemap + robots.txt

### فاز ۲ — کاربران و امنیت
- ثبت‌نام/ورود با ایمیل، بازیابی رمز، تایید ایمیل، ویرایش پروفایل، تغییر رمز
- 2FA (TOTP)، مدیریت نشست‌ها، Audit Log، Rate Limiting در server functions
- Input validation با Zod، sanitization، CSP headers

### فاز ۳ — محتوا (دوره + مقاله)
- CRUD دوره با فصل/درس/فایل، دسته‌بندی، جستجو، فیلتر
- ویرایشگر مقاله پیشرفته با syntax highlight و copy code
- امتیاز، نظر، پرسش‌وپاسخ

### فاز ۴ — اشتراک و فضای ابری
- پلن‌های Free/VIP/Gold/Enterprise، کد تخفیف
- فضای ۱GB برای VIP: آپلود، پوشه‌بندی، مصرف، حذف

### فاز ۵ — پنل ادمین کامل + گزارش‌ها + تیکت
- داشبورد آمار، مدیریت همه موجودیت‌ها، لاگ‌ها، backup

### فاز ۶ — یکپارچه‌سازی‌های خارجی (نیاز به تصمیم شما)
- پیامک (کدام سرویس؟)، پرداخت (کدام درگاه؟)

## مواردی که به آن‌ها نمی‌رسم و باید بدانید

- **Laravel/NestJS/Docker/Nginx/MySQL/Redis**: در Lovable Cloud پشتیبانی نمی‌شود. استک فعلی همان چیزی است که خواسته‌های امنیتی‌تان را برآورده می‌کند (Postgres + RLS + TLS خودکار + Edge).
- **پیامک و پرداخت**: بعد از انتخاب شما اضافه می‌کنم (کلید API لازم است).
- **CTF / انجمن / اپ موبایل / AI**: ماژول‌های آینده هستند، معماری فعلی برایشان آماده می‌شود ولی پیاده‌سازی نمی‌شود مگر جداگانه بخواهید.

## سوال از شما

آیا موافقید با **فاز ۱** شروع کنم (طراحی جدید + همه صفحات ساختاری + RBAC + SEO)؟ همه چیز فعلی (وبلاگ، پست‌ها، تیم، پنل ادمین موجود، لاگین با یوزرنیم تلگرام) دست‌نخورده باقی می‌ماند و فقط گسترش می‌یابد.

اگر تایید کنید، فاز ۱ را شروع می‌کنم. اگر ترتیب فازها را می‌خواهید عوض کنید، بگویید.
